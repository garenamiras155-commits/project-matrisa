# Matrisa учебный магазин

Демонстрационный интернет-магазин на Next.js App Router и JavaScript. Товары хранятся в локальном массиве, корзина сохраняется только в браузере через `localStorage`, настоящей оплаты и отправки заказа нет.

## Локальный запуск

```bash
npm install
npm test
npm run build
npm run start
```

После запуска откройте `http://localhost:3000`.

Основные маршруты:

- `/` — каталог;
- `/checkout` — оформление учебного заказа;
- `/catalog` — переход обратно в каталог;
- `/api/orders` — учебное логирование snapshot заказа в терминал, без базы данных.

## Публикация через GitHub

1. Создайте пустой репозиторий в своём GitHub-аккаунте.
2. В корне проекта выполните:

```bash
git init
git add .
git commit -m "Initial educational store"
git branch -M main
git remote add origin https://github.com/<YOUR_LOGIN>/<YOUR_REPOSITORY>.git
git push -u origin main
```

3. Не добавляйте реальные пароли, токены или персональные данные. Для учебного заказа используйте вымышленные контакты.

## Публикация через Vercel

1. Откройте Vercel и выберите **Add New Project**.
2. Импортируйте GitHub-репозиторий.
3. Оставьте настройки Next.js по умолчанию.
4. Нажмите **Deploy**.
5. После публикации проверьте URL проекта и маршруты `/`, `/checkout` и `/catalog`.

После каждого изменения:

```bash
git add .
git commit -m "Describe the update"
git push
```

Vercel автоматически соберёт новую версию из `main`. После деплоя повторите путь: каталог → товар → корзина → `/checkout` → подтверждение.

## Ограничения учебной версии

- база данных не используется;
- корзина привязана к браузеру и не синхронизируется между устройствами;
- заказ не отправляется продавцу;
- API `/api/orders` только выводит данные учебного заказа в терминал;
- изображения загружаются с Unsplash и могут быть недоступны в окружении с блокировкой внешних ресурсов.
